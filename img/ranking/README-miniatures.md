# Miniatures dels rànquings — electricos.eu

Objectiu: fotografies reals de perfil lateral estricte, morro a l'esquerra, quatre rodes visibles, fons transparent i marge homogeni. Sortida WebP 600×320 px, vehicle ocupant aproximadament el 84% de l'amplada i centrat verticalment. No generar imatges de cotxes amb IA ni deformar proporcions. Verificar model/any i permisos de reutilització de cada fotografia abans de publicar.

Les imatges existents a `img/ranking/` s'han de reutilitzar si compleixen el criteri. Les absents no s'han de substituir per altres models.
